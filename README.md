# Ground Control

El cockpit inteligente para un Xiaomi Electric Scooter 6 Ultra: experiencia de conducción inspirada en Tesla, misiones y bitácora inspiradas en aviación y SpaceX.

Proyecto personal en build in public. Estado: planificación y factibilidad; todavía sin aplicación ni integración Xiaomi comprobada.

Desarrollo: OpenCode con Big Pickle como modelo principal; Cursor sólo cuando sea necesario. Gestión de producto: ChatGPT como AI Product Manager junto con Alejandro.

El roadmap, las tareas y las instrucciones de trabajo se incorporan en el próximo commit documental.
